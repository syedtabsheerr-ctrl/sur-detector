Scores are based only on samples where both your pitch and a target note were detected. They measure pitch closeness, not vocal quality, pronunciation or musical expression.
The reference melody provides note events with start and end times. The audio player's current time selects the target note. The microphone signal is analysed with a YIN-style fundamental-frequency estimator. The detected frequency is converted to MIDI pitch and compared with the target in cents. Use the alignment offset to correct small timing differences. The chart draws the reference note blocks and your measured pitch trace on the same time/pitch axes.
JSON structure: { "title": "My song", "notes": [{"start": 0, "end": 0.5, "note": "A3"}] }. Every note needs start and end times in seconds and a pitch such as C4, F#3 or Bb3. CSV columns: start,end,note. MIDI imports expose separate tracks where possible; choose the vocal melody track by importing a track-specific MIDI or editing the resulting notes.
This page processes microphone audio in your browser. It does not send microphone recordings or song files to a server. Recording is optional and downloads a local WebM/Opus file where supported. Microphone access requires HTTPS or localhost. Use headphones to reduce backing-track bleed. Pitch detection from a mixed recording is imperfect, particularly with vibrato, breathy notes, loud instruments and octave-rich sounds. A correct reference melody and correct timing are required for meaningful scores.
